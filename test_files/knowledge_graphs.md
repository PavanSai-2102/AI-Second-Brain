# Knowledge Graph Systems

Knowledge graphs represent information as interconnected entities (nodes) and 
relationships (edges). They power search engines (Google Knowledge Graph), 
recommendation systems, and question-answering pipelines.

## Key Concepts
- **Nodes**: Entities (people, places, concepts)
- **Edges**: Relationships between entities
- **Properties**: Attributes attached to nodes or edges

## Applications in Personal Knowledge Management
- Auto-linking related notes via semantic similarity
- Visualizing idea clusters and knowledge gaps
- Enabling graph-based search and traversal

Force-directed graph layouts (like Cytoscape.js's COSE algorithm) use 
physics simulation to position nodes — connected nodes attract, while 
unconnected nodes repel, creating natural visual clusters.
